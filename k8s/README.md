# k8s/

`datacenter.sh` applies Kubernetes manifests and Helm charts from this directory
(Chapter 13–16). The book names the files but does not include their full YAML
in a downloadable tree (for example `myapp-namespace.yaml`, `registry.yaml`,
`service-account.yaml`, `disks/local-volume.yaml`).

Add those manifests here as you follow the book. `--dry-run` does not require
them to be present.
